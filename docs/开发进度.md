## 关键决策记录

| # | 决策 | 理由 |
|---|------|------|
| 1 | 整体采用「保守方案」，不做过度建模 | MVP 优先跑通核心链路 |
| 2 | 否决 String → Prisma enum | SQLite 连接器不支持 Prisma enum |
| 3 | Prisma 降级到 6.19.3 | Prisma 7 的 `datasource.url` 破坏性变更对 MVP 零收益 |
| 4 | 专家状态不落库 | 瞬态数据，只走内存 + SSE，避免双真相源 |
| 5 | 共识必须追溯来源 | 反幻觉可测试性的硬前提 |
| 6 | summary 单一真相源 | 共识点只存 ConsensusItem，总结只存 Discussion.summary |

## 技术约束（实现时必须遵守）

1. **Prisma 不要升回 7**，否则报 `P1012 datasource.url` 错误
2. **嘉宾状态**走 `Map<discussionId, Map<memberId, RuntimeState>>` 内存态 + SSE `status_update`
3. **轮次节奏**：主持人开轮（`Round.status=open`）→ 专家发言挂 `roundId` → 关轮时触发一次共识提炼
4. **共识溯源必写**：创建 `ConsensusItem` 时必须同时写 `ConsensusItemMessage` join 行
5. **字符串枚举用 Zod 校验**：`waiting/generating/ongoing/finished`、`speech/internal/summary`、
   `consensus/divergence`、`open/closed`、`host/expert`
6. **`Message.roundId` 可空**：开场前发言允许为 null
